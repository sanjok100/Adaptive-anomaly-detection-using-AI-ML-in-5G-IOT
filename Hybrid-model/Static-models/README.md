
# Hybrid Anomaly Detection System (VAE + XGBoost) for 5G-NIDD

## Project Overview

This project implements a hybrid anomaly detection framework using a Variational Autoencoder (VAE) and Extreme Gradient Boosting (XGBoost) model on the 5G-NIDD dataset.

The framework combines deep feature extraction using VAE with classification using XGBoost to improve anomaly detection performance on structured 5G network traffic data.

---

## -------- Level 1 Binary Classification --------

### The system performs:

1. Binary classification (Benign vs Attack)
2. Feature extraction using VAE
3. Classification using XGBoost
4. Hyperparameter tuning
5. Model evaluation

The goal is to detect malicious network traffic by combining compressed feature representations with efficient classification.

---

## Workflow Pipeline

### 1) Data Preprocessing

Missing values are handled using median/mode filling.

Categorical features are converted using one-hot encoding.

Binary labels are created:

* 0 = Benign
* 1 = Attack

---

### 2) Feature Engineering and Representation Learning

Input features are normalized using StandardScaler.

A Variational Autoencoder (VAE) is trained to learn compressed latent representations of network traffic.

The encoder output is extracted and used as input features for classification.

---

### 3) Train / Validation / Test Split

Dataset split:

* 80% Training
* 10% Validation
* 10% Testing

Stratified sampling is applied to preserve class distribution.

---

### 4) Class Balancing

Training data is balanced using oversampling to reduce class imbalance.

---

### 5) Hybrid Model Architecture

#### Variational Autoencoder (VAE)

The VAE contains:

* Input Layer
* Encoder Dense Layers
* Latent Space
* Decoder Dense Layers
* Reconstruction Output

The encoder learns compressed feature representations.

#### XGBoost Classifier

Latent features generated by VAE are passed into XGBoost.

XGBoost performs:

* Gradient boosted decision tree learning
* Final binary prediction

---

### 6) Hyperparameter Tuning

Model parameters are optimized using:

* GridSearch
* Cross-validation

Parameters include:

* Latent dimensions
* Learning rate
* Number of estimators
* Maximum tree depth
* Regularization values

---

### 7) Evaluation

Performance is evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Classification Report
* Confusion Matrix (raw and normalized)

---

## -------- Level 2 Multi-class Attack Category Classification --------

### The system performs:

1. Attack traffic filtering
2. Feature extraction using VAE
3. Multi-class classification using XGBoost
4. Hyperparameter tuning
5. Model evaluation

Attack categories:

* DoS
* Scan
* SlowrateDoS

Objective:
Classify malicious traffic into broader attack categories for structured threat analysis.

---

## Workflow Pipeline

### Attack Type Encoding

Individual attack types are grouped into categories:

* DoS → ICMPFlood, UDPFlood, SYNFlood, HTTPFlood
* Scan → SYNScan, TCPConnectScan, UDPScan
* SlowrateDoS

LabelEncoder is used to convert categories into numerical labels.

---

### Class Balancing

Oversampling and downsampling are applied to reduce category imbalance.

---

### Evaluation

Performance metrics:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix
